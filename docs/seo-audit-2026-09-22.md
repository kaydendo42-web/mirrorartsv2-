# SEO / AEO audit — 22 September 2026

One-time audit and quick-win pass, planned in `docs/SEO-PICKUP.md` and executed from
`docs/superpowers/plans/2026-09-22-seo-audit-and-fixes.md`.

**Method.** `scripts/seo-crawl.mjs` reads the sitemap and grades every URL: HTTP status,
title and description length, H1 count, canonical, `og:image`, JSON-LD validity and types,
images without alt, every internal link (HEAD). Run once against the live site
(`www.mirrorartsedu.com.au`, the *before*) and once against the local production build
(the *after*). Lighthouse on four template pages, mobile simulation. Rank snapshot in its
own section. No Search Console existed at the time, so there is no query data.

Thresholds: a title over 60 or a description over 165 characters is a *note* (Google cuts
the tail); over 80 / 230 is an *issue*. Everything else listed is an issue.

**Reading.**

1. **The old site outranks the new one for the school's own name.** `mirrorartsedu.com`
   is still live (a Chinese site-builder host; DNS at `dlszywz.com`; the apex 308s to its
   own https) and holds #1 for "mirror arts education", with its mobile page at #8. The
   new `.com.au` is #3. Google is splitting the brand between two sites. The fix is not in
   this codebase: the old site must 301 every URL to `https://www.mirrorartsedu.com.au/`
   (the mail on `@mirrorartsedu.com` is MX and is unaffected by a web redirect). This is
   the single largest gain available and it is the first item on the off-site list.
2. **The map pack is where local searches are won, and the school is not in it.** For
   "drama classes surrey hills" the site is #3 organically — under three map-pack
   listings that a parent sees first. That is Google Business Profile: address, hours,
   photos, reviews. Item 2 on the off-site list.
3. Category searches without a suburb ("performing arts school for kids melbourne") are
   held by chains with many pages and many links (Stage School, Stagecoach, Stage Left).
   Not a page-1 target for a two-campus school without links; the suburb queries are.
4. The changes shipped here make the site *eligible* — one host, canonicals, cards,
   breadcrumbs, FAQ — and change what the result looks like. They do not move these
   positions on their own. Recheck in Search Console four weeks after the old-site
   redirect and the GBP work land.

## Redirect — apex to www, 307 today

`mirrorartsedu.com.au` is not attached to either Vercel project; only `www` is on
`mirrorartsv2`. Vercel serves an implicit 307 for the unassigned apex. Making it a
permanent 308 means adding the apex to the project as a redirect. The MCP call to do it was
blocked by the session's permission policy (domain change), so it is a one-liner for Kayden:

```
Vercel → kaydendo42-webs-projects → mirrorartsv2 → Settings → Domains → Add
  mirrorartsedu.com.au  →  Redirect to www.mirrorartsedu.com.au  →  308 Permanent
```

or, from a terminal with the CLI logged in:

```bash
vercel domains add mirrorartsedu.com.au mirrorartsv2 --scope kaydendo42-webs-projects
# then set the redirect in the dashboard (the CLI adds the domain; the 308 is a dashboard field)
```

DNS already points the apex at Vercel (`A 216.198.79.1`), so it verifies immediately.
Check: `curl -sI https://mirrorartsedu.com.au/ | head -1` → `HTTP/2 308`.

   site is live and holds #1 for the school's own name (see the rank baseline). Every URL on
   it should permanently redirect to the same path on the new site, or to the homepage
   where there is no equivalent. That is done at the old site's host or registrar (DNS is at
   `dlszywz.com`, a Chinese site-builder). Email on `@mirrorartsedu.com` is MX, separate from
   the web redirect, and keeps working. Until this lands, Google splits the brand between
   two sites and gives the old one the top spot.

   Google login). Set the website to `https://www.mirrorartsedu.com.au`, confirm both campus

   hours, the photographs already on the site, and start asking parents for reviews. This is
